# BOMBER 2090

Неоновый Bomberman на чистом Canvas 2D — без сборки и зависимостей.

## Запуск

Открой `index.html` в браузере, либо:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## Управление

- `WASD` / стрелки — движение
- `Space` — бомба
- `Shift` — рывок
- `P` / `Esc` — пауза
- `M` — звук вкл/выкл
- `N` — музыка вкл/выкл
- `−` / `+` (или колесо над ползунком) — громкость музыки
- Тач: стик слева, бомба справа

Ползунок музыки — в правом верхнем углу, громкость сохраняется в `localStorage`.
